# MLP 参数学习的实现与可视化

在线报告：https://hanzheyu01.github.io/mlp-learning-report/

源码仓库：https://github.com/hanzheyu01/mlp-learning-report

公开报告托管在个人网站仓库的独立目录，页面内嵌样式、训练实现和实验数据；本仓库保留可复现的模块化源码。当前仓库无需另行开启 Pages。

第二次作业：通用 MLP 实验报告。未提供指定课程原文，按通用前馈网络、反向传播与梯度下降实现。

## 运行

Node.js 18 或更新版本，无第三方依赖。

```sh
npm test
npm run experiment
```

将本目录通过静态 HTTP 服务或 GitHub Pages 托管，打开 index.html。不要直接双击 HTML（浏览器模块与 fetch 需要 HTTP）。

## 实验

- XOR 数据：x 在 [-1,1]² 均匀分布，异号为 1，同号为 0。
- 400 训练点 / 400 独立测试点，种子分别为 42 / 2026。
- 2→8→1，tanh 隐藏层、sigmoid 输出，33 参数，Xavier 初始化种子 7。
- 稳定二元交叉熵，全批量梯度下降，3000 轮。
- 学习率 0.03、0.3、1；同数据逻辑回归基线。
- 默认学习率 0.3：训练准确率 98.75%，测试准确率 97.50%。完整原始结果见 results.json。

## 文件

- mlp.js：前向传播、手写梯度、更新、数据生成与线性对照。
- experiment.mjs：独立运行实验，生成结果文件。
- verify.mjs：所有参数中心差分梯度检查、收敛和可复现性验证。
- index.html / app.js / style.css：中文报告、在线训练、损失和边界、参数热力图、JSON 导出及打印。

## 验证与局限

梯度中心差分 epsilon=1e-5，最大绝对误差 1.80e-11。测试集不参与更新。实验仅为单一无噪声合成任务和单个划分，不代表真实任务性能。网页学习率和结构可调；结果表固定来自命令行实验，不随交互改变。

参考：[Deep Learning, Chapter 6](https://www.deeplearningbook.org/contents/mlp.html)。

## 深圳低空经济与空天产业：教学情景预测

报告新增 `#shenzhen` 章节。真实基准为 2025 年深圳低空经济与空天产业集群增加值 **350.61 亿元**，来自 [深圳政府在线 2026-02-27 报道](https://www.sz.gov.cn/cn/xxgk/zfxxgj/zwdt/content/post_12657458.html)。该口径包含空天产业，不等于纯低空产业总产值。

**这是模拟情景代理模型，不是根据深圳历史数据训练的实证预测。** 只有一个真实规模基准点；训练与测试数据均由人工规则生成。2026 年是情景估算，2027—2030 年是条件情景预测，不提供置信区间或现实预测准确率。

人工规则：`g = 0.04 + 0.45*d + 0.10*c + 0.12*d*c - 0.12*r`。d 为需求增长假设 [0,0.4]，c 为商业化指数 [0,1]，r 为运营约束指数 [0,1]；系数不是从真实数据估计。模型 3→8→1、tanh 隐藏层、线性输出、MSE，41 参数；输入映射到 [-1,1]，目标为 g/0.3。600/200 个模拟训练/测试样本，种子 101/202；初始化种子 19，学习率 0.05，3500 轮。

测试增速 MAE 约 0.299 个百分点，训练均值基线约 6.046 个百分点，仅衡量公式拟合误差。全部参数数值梯度最大误差约 2.41e-11。审慎/中性/积极 2030 年情景值约 480/820/1190 亿元，不是保证值。需求等假设每年不变，未进行价格平减。

背景事实与政策目标分别列示：[深圳市发展改革委 2025 执行情况与 2026 计划](https://fgw.sz.gov.cn/fzgggz/jjxs/content/post_12846529.html)。2025 年末起降点 1284 个、低空物流航线 310 条是背景数据；2026 年产业规模超 1300 亿元是不同口径的计划目标，均不作为训练标签。资料核查日 2026-11-13。

```sh
npm run build:public   # 打包 public-report.html，可本地直接打开或发布
```
