01 / QUESTION & METHOD

让网络学会 XOR

输入 x₁、x₂ 在 [-1,1] 内均匀采样；异号时标签为 1，同号时为 0。这个任务不能用一条直线完整分开，适合观察隐藏层的非线性表示能力。训练集 400 个点（种子 42），独立测试集 400 个点（种子 2026）。标签没有额外噪声，样本靠近坐标轴时更难判断。

前向传播

z₁ = xW₁ + b₁
h  = tanh(z₁)
z₂ = hW₂ + b₂
p  = sigmoid(z₂)

W₁ ∈ ℝ²ˣ⁸，b₁ ∈ ℝ⁸，W₂ ∈ ℝ⁸ˣ¹，b₂ ∈ ℝ。共 16 + 8 + 8 + 1 = 33 个参数。权重使用 Xavier 均匀初始化，偏置为零，模型种子为 7。

反向传播与更新

δ₂ = (p − y) / N
∇W₂ = hᵀδ₂ ; ∇b₂ = Σδ₂
δ₁ = (δ₂W₂ᵀ) ⊙ (1 − h²)
∇W₁ = Xᵀδ₁ ; ∇b₁ = Σδ₁
θ ← θ − η∇θ

损失采用二元交叉熵；实现使用等价的稳定 logit 形式 max(z,0) − yz + log(1+exp(−|z|))。每轮对全部训练数据计算平均梯度；测试数据不参与更新。

03 / RESULTS & DISCUSSION

观察与解释

默认 η=0.3 时，训练损失从 0.694103 降至 0.061802，测试准确率达到 97.50%。隐藏层 tanh 提供非线性变换，输出层再组合这些特征，形成弯曲的分类区域。参数学习体现为全部权重和偏置的连续更新，而非直接指定分类规则。

学习率改变相同预算下的收敛速度。这里的有限实验不意味着较大学习率总是更好；更换数据、初始化或结构可能出现震荡与不稳定。

正确性与局限

对全部 33 个参数进行中心差分检查（ε=10⁻⁵），解析梯度与数值梯度的最大绝对误差为 1.80×10⁻¹¹。另验证损失下降、测试准确率超过 90% 和随机数据可复现。

这是无噪声合成二维任务，单个数据划分不能说明真实任务泛化能力。报告未进行多种子统计、置信区间或超参数搜索。未获得指定课程原文，因此采用通用 MLP 定义，不声称逐项复现“第二篇第15节”。
