01 / QUESTION & METHOD

让网络学会 XOR

输入 x₁、x₂ 在 [-1,1] 内均匀采样；异号时标签为 1，同号时为 0。这个任务不能用一条直线完整分开，适合观察隐藏层的非线性表示能力。训练集 400 个点（种子 42），独立测试集 400 个点（种子 2026）。标签没有额外噪声，样本靠近坐标轴时更难判断。

前向传播

z₁ = xW₁ + b₁
h  = tanh(z₁)
z₂ = hW₂ + b₂
p  = sigmoid(z₂)

W₁ ∈ ℝ²ˣ⁸，b₁ ∈ ℝ⁸，W₂ ∈ ℝ⁸ˣ¹，b₂ ∈ ℝ。共 16 + 8 + 8 + 1 = 33 个参数。权重使用 Xavier 均匀初始化，偏置为零，模型种子为 7。

反向传播与更新

δ₂ = (p − y) / N
∇W₂ = hᵀδ₂ ; ∇b₂ = Σδ₂
δ₁ = (δ₂W₂ᵀ) ⊙ (1 − h²)
∇W₁ = Xᵀδ₁ ; ∇b₁ = Σδ₁
θ ← θ − η∇θ

损失采用二元交叉熵；实现使用等价的稳定 logit 形式 max(z,0) − yz + log(1+exp(−|z|))。每轮对全部训练数据计算平均梯度；测试数据不参与更新。

观察与解释

默认 η=0.3 时，训练损失从 0.694103 降至 0.061802，测试准确率达到 97.50%。隐藏层 tanh 提供非线性变换，输出层再组合这些特征，形成弯曲的分类区域。参数学习体现为全部权重和偏置的连续更新，而非直接指定分类规则。

学习率改变相同预算下的收敛速度。这里的有限实验不意味着较大学习率总是更好；更换数据、初始化或结构可能出现震荡与不稳定。

正确性与局限

对全部 33 个参数进行中心差分检查（ε=10⁻⁵），解析梯度与数值梯度的最大绝对误差为 1.80×10⁻¹¹。另验证损失下降、测试准确率超过 90% 和随机数据可复现。

这是无噪声合成二维任务，单个数据划分不能说明真实任务泛化能力。报告未进行多种子统计、置信区间或超参数搜索。未获得指定课程原文，因此采用通用 MLP 定义，不声称逐项复现“第二篇第15节”。

05 / SHENZHEN · SCENARIO FORECAST

深圳低空经济：未来五年的情景推演

真实基准 × 假设驱动 × MLP 回归演示。本案例没有用深圳历史序列训练预测模型。MLP 学习的是人工设定的情景公式，结果是“假设成立时会怎样”，不是官方预测，也没有经过现实样本外检验。

把 XOR 分类扩展为一个现实问题：在需求增长、商业化程度与运营约束不同的条件下，深圳相关产业的经济体量可能如何变化？为避免口径混用，预测对象限定为“低空经济与空天产业集群增加值”，其中包含空天产业，不能等同于纯低空经济总产值或企业营业收入。数据核查日期：2026-11-13。

先读懂模型，再看预测

不用公式，理解 MLP 在做什么

MLP 的全称是“多层感知机”。可以把它想成一台带有许多可调旋钮的计算器：你输入几个数字，它经过几层计算，给出一个答案。它没有人的理解能力，但能通过反复看例子，调整旋钮，让答案更接近训练样本提供的目标。

① 输入：把问题变成数字

在深圳案例里，输入是三个假设：需求增长多快、商业化有多成熟、运营约束有多强。例如“需求增长 22%、商业化 0.60、约束 0.30”。这些数字是我们设定的情景条件，不是模型自动调查得到的事实。

② 隐藏层：从几个角度组合信息

8 个隐藏单元像 8 个小计算器，各自用不同的权重组合三个输入，再做非线性变换。这样模型有机会表达“同样的需求增长，在商业化程度不同时，影响也可能不同”。这只是帮助理解的比喻；不能把某一个隐藏单元直接命名为“政策专家”或“市场专家”。

③ 输出：给出一个连续数值

输出层汇总隐藏层的结果，得到情景中的年增长率。程序再用这个增长率，从 2025 年的 350.61 亿元基准逐年计算后续规模。MLP 输出的是增长率；年度金额是随后通过复利公式算出的。

④ 学习：预测、对答案、微调

模型先试着预测，再与训练样本的目标比较。损失函数衡量差距；反向传播计算每个旋钮对误差的影响；梯度下降据此做小幅调整。反复训练后，模型可能更接近样本中的规律，但仍需要用没参与训练的数据检查。

“学习参数”到底是在学什么？

权重决定一条连接上的信号被放大、缩小还是反向；偏置调整计算单元的起点。它们是训练时被更新的参数。本案例有 41 个这样的参数。隐藏单元数量、学习率和训练轮数则由我们预先设置，称为超参数。学习率像每次拧旋钮的步幅：太小可能学得慢，太大可能来回震荡。

为什么需要“非线性”？

如果每一层都只做加权求和，多层叠加后仍相当于一次线性计算。tanh 这样的非线性函数让网络能够表达更复杂的关系。前面的 XOR 实验展示了这种能力；深圳案例则用它拟合假设公式中的“需求 × 商业化”交互项。

这个案例的“答案”从哪里来？

这里的训练答案由下方公开的人工公式生成。因此，MLP 学到的是我们写进模拟规则的关系，而不是发现了深圳经济的真实运行规律。已知公式时，直接代入计算更准确；引入 MLP 是为了演示回归模型如何学习参数。真实基准数据提供起点，不能把后续假设自动变成事实。

拖动滑块时，可以这样看

先选“中性情景”，只改变一个滑块，观察紫色曲线、增长率和年度金额如何变化，再恢复原值比较另一个因素。滑块改变的是输入条件，不会重新训练模型。这种比较展示模型在既定规则下的响应，不是现实世界的因果实验。测试误差很小，也只能说明它模仿这套规则较好。

从分类模型变为回归模型

采用 3→8→1 MLP，共 41 个参数。输入为需求年增长假设 d、商业化成熟度 c、运营约束 r；隐藏层仍为 tanh，输出层改为线性，损失改为均方误差。d 在 [0,0.4]，c、r 在 [0,1]，三个输入分别线性映射到 [-1,1]。c、r 是教学指数，没有观测量表。

g* = 0.04 + 0.45d + 0.10c
     + 0.12dc − 0.12r
目标 y = g* / 0.3
ŷ = W₂ tanh(W₁x + b₁) + b₂
L = mean((ŷ − y)²)
δ₂ = 2(ŷ − y) / N
g_MLP = 0.3 × ŷ
Vₜ = 350.61 × (1 + g_MLP)^(t−2025)

公式及全部系数均由本案例人为设定，未从深圳数据估计。交互项 dc 表示假设中的需求与商业化协同；约束项表示假设中的空域、天气、安全和成本摩擦。它们不构成经验证的因果关系。

训练与验证设计

在限定范围内独立均匀抽取 600 个训练情景和 200 个测试情景（种子 101、202），用上式生成标签。模型种子 19，Xavier 初始化、零偏置、全批量梯度下降，学习率 0.05，训练 3,500 轮。仅训练样本参与参数更新。

用中心差分核对全部 41 个参数的梯度，用训练标签均值作为测试对照。合成测试数据检验的是对既定公式的插值能力，并非对未来深圳经济的泛化能力。已知公式直接计算更准确；MLP 在这里用于展示从非线性输入到连续输出的学习过程。

如何理解结果

本次实际运行中，审慎、中性、积极情景的 MLP 年增速约为 6.46%、18.51%、27.69%，对应 2030 年约 480、820、1190 亿元。这些差异主要来自事先设定的规则与输入；不能据此断言深圳届时必然达到这些规模。较小的模拟 MAE 也不能转化成现实预测误差范围。

作为产业讨论，可进一步核查物流配送、巡检和公共服务的订单与单次成本，观察基础设施是否带来稳定使用率，跟踪载人场景的适航与运营进展。它们是待验证的观察方向，本模型没有证明哪种业务必然增长。

升级为可信预测还需要什么

收集同口径季度或月度增加值、实际订单、利用率、价格与成本、天气停航等数据；标记修订、缺失与政策变化；按时间先后拆分训练、验证和测试，并与不变值、趋势等简单模型对照。模型和调参仅使用预测时点以前可获得的数据。最后通过滚动回测评估误差，并区分模型误差、政策变化与情景假设的不确定性。

结论

本实验完成了 MLP 前向传播、交叉熵、反向传播和梯度下降的独立实现。数值梯度检查为实现正确性提供证据；独立测试和线性基线对照展示了非线性隐藏层在 XOR 任务上的作用。交互页面将参数更新、损失下降和决策边界连接起来，使学习过程可以观察与复现。
